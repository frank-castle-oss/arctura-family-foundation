# Public Sharing Boundary

This repository is intended to share the **public operating model** and implementation direction of the Arctura initiative. “Arctura Family Foundation” is a working name only; the legal entity is pending creation and final-name selection. It is not a public database, an open recipient directory, a donor system, or an operational command center.

## Included

The public repository may include reusable software, public editorial material, generalized vendor research, operating frameworks, data-model definitions, and non-sensitive integration contracts.

## Excluded

The public repository must never include credentials, environment values, payment or banking information, raw database exports, recipient information, personal contact details submitted through forms, private partner terms, route details, safety incidents, or internal access-control configuration.

## Publication gate

Before any public push, contributors must review new and changed files for secrets and for personal or operationally sensitive information. Documentation must distinguish between proposed standards, planning-stage work, verified active programs, and evidence-based outcomes.
